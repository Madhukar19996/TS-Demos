Quick Refresher — Multi-Variable Declaration

📖 Shortcut Syntax

Instead of multiple let statements, declare several variables in one single statement using commas.

// Long way
let a: number = 10;
let b: number = 20;

// Shortcut — one statement
let a = 10, b = 20;

Variables can even have different data types in the same statement.

🟰 Assignment (Shorthand) Operators

📖 Concept

= is the base assignment operator. Combined with arithmetic ops → shorthand operators that update a variable using its own current value.

ShorthandEquivalent To
a += ba = a + b
a -= ba = a - b
a *= ba = a * b
a /= ba = a / b
a %= ba = a % b
🚨 The Chained-Operations Trap

Each shorthand op uses the already-updated value of a, not the original! Trace it step by step:

let a = 10, b = 5;
a += b; // a = 10+5 = 15
a -= b; // a = 15-5 = 10 (NOT 10-5=5!)
a *= b; // a = 10*5 = 50
a /= b; // a = 50/5 = 10
a %= b; // a = 10%5 = 0

Redeclaration not possible with same let, but reassignment is always possible.

⭐ TOP INTERVIEW QUESTION — == vs ===
== Equality

Compares values only, ignores data type.

let num1: any = 10; // number
let num2: any = "10"; // string
console.log(num1 == num2); // true
=== Strict Equality

Compares values AND data type — TS/JS-only, not found in other languages.

console.log(num1 === num2); // false // same value, different type → fails

Memory Trick 🧠: "3 equals = 3 checks" (value + type + no coercion)

🔗 Logical Operators

📖 Key Rule

Only 3 logical operators: && (AND), || (OR), ! (NOT). Work only between boolean values and always return boolean.

AND (&&): BOTH must be true — strict, like a picky bouncer 🚪
OR (||): only ONE needs to be true — easy-going 🤝
NOT (!): simply flips the value — true↔false 🔄
Mixing Logical + Relational Operators
console.log(20 > 10 && 10 > 5); // true && true → true
console.log(10 < 20 || 5 > 10); // true || false → true

Very common in conditional statements & loops — combining multiple checks into one expression.

🔼🔽 Increment & Decrement Operators

📖 Basics

++ increases value by 1. -- decreases value by 1. Each has a pre and post variant.

🔸 Post-Increment (x++)

Variable specified first, operator after. Assign THEN increment.

let x = 10;
let result = x++;
console.log(result); // 10 (old value assigned)
console.log(x); // 11 (then incremented)
🔹 Pre-Increment (++x)

Operator first, variable after. Increment THEN assign.

let x = 10;
let result = ++x;
console.log(result); // 11 (incremented first)
console.log(x); // 11
🚨 The Classic Gotcha

If you just write x++; or ++x; alone (not storing the result), there is NO visible difference — both give the same final value of x. The difference only shows up when you immediately assign the expression's result to another variable!

TypeBehaviorExample (x=10)
Post (x++ / x--)Assign old value → THEN change xresult=10, x becomes 11
Pre (++x / --x)Change x FIRST → THEN assign new valueresult=11, x becomes 11

❓ Ternary (Conditional) Operator

📖 Syntax
condition ? valueIfTrue : valueIfFalse;

A compact replacement for if-else — condition must evaluate to true/false.

Example 1 — Max of Two Numbers
let a = 100, b = 200;
let result = a > b ? a : b;
console.log(result); // 200 (b, since a>b is false)
Example 2 — Adult or Minor Check
let personAge = 30;
let result: string = personAge >= 18 ? "Adult" : "Minor";
console.log(result); // "Adult"
Only 2 outcomes allowed — true-branch & false-branch. No third option!
9

⚡ Exam-Trick & Frequently Tested Points

Trick 1 — "Difference between == and ===?"

== compares values only (type coercion happens). === compares values AND types — no coercion. This is a TS/JS-only operator, not in Java/Python.

Trick 2 — "Difference between / and %?"

/ → quotient. % → remainder. Classic beginner mix-up.

Trick 3 — "When does pre/post increment actually matter?"

Only when the increment expression's result is captured in another variable (e.g., inside an assignment or function call) — standalone x++; shows no visible difference.

Trick 4 — "What can replace an if-else block?"

The ternary operator — reduces multiple lines of if-else into one compact expression. Great for simple binary decisions.

Trick 5 — "Do logical operators work on numbers?"

No — &&, ||, ! work only on boolean values. Relational expressions (which return booleans) can feed into them though.

Final One-Page Memory Sheet

➕ Arithmetic

+ − * / % ** — division gives quotient, % gives remainder, ** is exponent.

🟰 Assignment

a += b means a = a + b. Chained ops use the already-updated value each time.

⚖️ Relational

Always returns boolean. == checks value only; === checks value + type (TS/JS special).

🔗 Logical

&&, ||, ! — work only on booleans. AND needs both true, OR needs at least one true.

🔼 Inc/Dec

Post (x++): use-then-change. Pre (++x): change-then-use. Only visible when result is captured.

❓ Ternary

condition ? valTrue : valFalse — compact if-else replacement, exactly 2 outcomes.
