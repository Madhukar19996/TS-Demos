What is a Loop? Why Do We Need It?

📖 Definition

A loop (iteration) = repeating a block of statements multiple times based on a condition, instead of writing the same statement over and over.

❌ Without Loop
console.log(1);
console.log(2);
console.log(3);
console.log(4);
console.log(5);

5 separate statements to print 5 numbers!

✅ With Loop
let i = 1;
while (i <= 5) {
  console.log(i);
  i++;
}

1 block, repeated 5 times automatically.

🔑 The 3 Must-Knows Before Writing ANY Loop
  1. Initialization — where do we start?
  2. Condition — where do we stop?
  3. Increment/Decrement — how much do we change each time?

Identify these 3 things first — writing the loop becomes automatic after that.

🔄 while Loop

let i = 1; // 1. initialization
while (i <= 5) { // 2. condition checked FIRST
  console.log(i);
  i++; // 3. increment
}
i = 1 (init)
↓
check: i <= 5 ?
↓ true
print i, then i++
↺ back to check
Example — Print Even Numbers 2 to 10 (no % operator)
let i: number = 2;
while (i <= 10) {
  console.log(i);
  i += 2; // start at 2, jump by 2 → all evens
}

Logic trick: start=1 & step=2 → odd numbers. start=2 & step=2 → even numbers.

Example — Same Logic Using % (Modulus)
let i: number = 1;
while (i <= 10) {
  if (i % 2 === 0) {
    console.log(i); // only print if even
  }
  i++;
}

Combine looping + conditional statement — very common pattern.

Descending Order Example
let i: number = 10;
while (i >= 1) {
  console.log(i);
  i--; // decrement instead of increment
}
🚨 THE INFINITE LOOP TRAP
while (true) {
  console.log(1); // condition NEVER becomes false → runs forever!
}

Rule: The condition MUST become false at some point, or you get an infinite loop — needs a forced exit (Ctrl+C). Always double-check your increment/decrement logic!

4

▶️ do-while Loop

📖 The Big Difference

while: checks condition BEFORE executing → may run zero times.
do-while: executes AT LEAST ONCE before checking condition — even if condition is false from the start!

let i = 1;
do {
  console.log(i);
  i++;
} while (i <= 5); // note: semicolon required here!
🚨 Proof: The "Runs Even When False" Case
let i = 10;
do {
  console.log(i); // prints 10 anyway!
  i++;
} while (i <= 5); // 10<=5 is FALSE from the start
// Output: just "10" — block ran once before check

In a regular while loop, this same condition would produce zero output. That's the core interview point.

🔢 for Loop

📖 Why Prefer for Loop?

while/do-while need at least 3 separate statements (init, condition, increment). for loop packs all 3 into ONE line — much less code, especially with many loops in a program.

for (initialization; condition; increment/decrement) {
  // statements
}
① Initialization (runs ONCE)
↓
② Condition check
↓ true
③ Execute statements
↓
④ Increment/Decrement
↺ back to ② condition
Example — Print 1 to 10
for (let i = 1; i <= 10; i++) {
  console.log(i);
}
Example — Even Numbers (step +2) & Descending Order
// even numbers
for (let i = 2; i <= 10; i += 2) { console.log(i); }

// descending 10 to 1
for (let i = 10; i >= 1; i--) { console.log(i); }
⭐ TOP INTERVIEW TRAP — Global vs Local Variable in for Loop
Case A: var declared with `let` INSIDE for(...)
for (let i = 1; i <= 5; i++) { }
console.log(i); // ❌ Error: i doesn't exist here

let inside for(...) = local to the loop only.

Case B: var declared OUTSIDE, reused inside
let i: number;
for (i = 1; i <= 5; i++) { }
console.log(i); // ✅ prints 6

No let inside for(...) = reusing the global/outer variable — accessible after the loop!

Why 6, not 5? After the last valid iteration (i=5), the loop increments i to 6, THEN checks the condition (6<=5 → false) and exits. The final value carried is 6.

🚨 The Semicolon-Only for Loop (No Block!)
let i: number;
for (i = 1; i <= 5; i++); // semicolon = empty block!
console.log(i); // prints 6 — loop still ran, just did nothing each time

Putting ; right after for(...) creates an empty statement block — the loop still runs and updates i, it just has nothing to execute inside.

🛑⏭️ Jumping Statements: break & continue

🛑 break — Exit the Loop Entirely
for (let i = 1; i <= 10; i++) {
  if (i === 5) {
    break;
  }
  console.log(i);
}
// Output: 1 2 3 4 (stops completely, 5 not even printed)
⏭️ continue — Skip This Iteration Only
for (let i = 1; i <= 10; i++) {
  if (i === 5) {
    continue;
  }
  console.log(i);
}
// Output: 1 2 3 4 6 7 8 9 10 (only 5 is skipped)
🚨 Skipping Multiple Values — Use OR, Never AND!
// ❌ WRONG — logically impossible
if (i === 3 && i === 5 && i === 7) { continue; }
// i can never equal 3 AND 5 AND 7 at the same time!

// ✅ CORRECT — use OR
if (i === 3 || i === 5 || i === 7) { continue; }

Golden Rule: A single variable can only equal ONE value at a time — checking "equals A AND equals B" is always false. Use && only for range checks (e.g., i > 5 && i < 10).

StatementEffectUse When
breakExits the ENTIRE loop immediatelyYou want to stop early based on a condition
continueSkips only the CURRENT iteration, loop continuesYou want to exclude specific values from processing

⚡ Exam-Trick & Frequently Tested Points

Trick 1 — "Difference between while and do-while?"

do-while guarantees at least 1 execution even if the condition is false from the start. while may run zero times.

Trick 2 — "What happens if you forget increment/decrement?"

Infinite loop — condition never becomes false, program hangs until forcefully stopped.

Trick 3 — "break vs continue?"

break = exit loop completely. continue = skip just this iteration, keep looping.

Trick 4 — "Is the loop variable accessible after the loop ends?"

Only if declared outside with let/var and reused inside for(...) without redeclaring. If declared with let INSIDE for(...), it's scoped only to the loop.

Final One-Page Memory Sheet

🔄 while

Checks condition BEFORE running. May execute zero times if condition starts false.

▶️ do-while

Executes block FIRST, checks condition AFTER. Guaranteed at least 1 run. Needs semicolon after while(...).

🔢 for

init; condition; increment — all in one line. Best when start/end/step are known upfront.

🛑 break vs ⏭️ continue

break = exit loop entirely. continue = skip current iteration, keep going.

🌍 Scope in for loop

let inside for(...) = local only. Variable declared outside & reused = accessible after loop ends.

🚨 Infinite Loop

Condition never turns false = runs forever. Always verify your increment/decrement logic.
