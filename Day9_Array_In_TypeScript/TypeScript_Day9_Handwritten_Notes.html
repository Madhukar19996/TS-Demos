What is an Array?

📖 Definition

A special variable that stores multiple values — same type or mixed types — unlike a primitive variable which holds only ONE value at a time.

In Java: Array ≠ ArrayList (two different things)
In TS/JS: Array itself IS the collection — no separate "ArrayList"

Arrays are an "ordered collection" — the order you insert values is the order they're stored & retrieved.

2

🔢 Indexing — The Core Concept

📖 Index = Position/Address of an Element

Indexing always starts at 0. For an array of length N, the last valid index is N - 1.

"John"
0
"Smith"
1
"Peter"
2
"Scott"
3
⭐ CRITICAL — length vs Last Index

.length returns how many elements exist (4 here), NOT the last index. Last index = length - 1 = 3 in this example. Mixing these up is the #1 off-by-one bug source.

3

📦 Declaring Arrays — 2 Approaches

Approach 1 — Literal (Square Bracket)
let names: string[] = []; // declaration only
names[0] = "John";
names[1] = "Smith";

// OR declare + initialize together:
let names: string[] = ["John", "Smith", "Peter", "Scott"];
Approach 2 — Generic (Array<type>)
let empNames: Array<string> = ["John", "Smith"];
let empIds: Array<number> = [101, 102, 103];

// mixed types via union
let data: Array<string | number> = ["John", 25, "Kate"];

// any type at all
let mixedData: Array<any> = [1, "hi", true, null];
Note 🧠
Both approaches work identically — Array<type> style is more commonly preferred in TS/JS codebases.
Arrays are Dynamic — No Fixed Size!

Unlike some languages, TS/JS arrays don't require a fixed size upfront. You can keep adding values freely. (A fixed-size, fixed-type version does exist — that's called a tuple, covered later.)

4

🔁 3 Ways to Loop Through an Array

Array Iteration
↙
Traditional for
Manual index, full control
↓
for...in
Auto index, still index-based
↘
for...of
Direct VALUE, no index at all
1️⃣ Traditional for Loop
for (let i = 0; i < empNames.length; i++) {
  console.log(empNames[i]);
}

Use i < length, never i <= length — that would try to access one index past the array's end.

2️⃣ for...in Loop (still index-based)
for (let i in empIds) {
  console.log(empIds[i]); // i is the INDEX, must still access via []
}

No manual initialization, condition, or increment needed — but i still represents an index, so you access the value with arrayName[i].

3️⃣ for...of Loop (direct value, no index!)
for (let value of mixedData) {
  console.log(value); // value IS the element itself
}

Equivalent to "for each" — the loop variable holds the actual value, not a position. This is the key difference from for...in.

🧩 Arrays + Functions

📖 Key Insight

An array is just a variable — so it can be passed as a function parameter AND returned from a function, just like any primitive.

Example — Passing an Array IN (Search Function)
function search(element: number, arr: number[]): boolean {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === element) {
      return true;
    }
  }
  return false;
}

let arr: number[] = [10, 20, 30, 40, 50];
console.log(search(30, arr)); // true
console.log(search(100, arr)); // false
Example — Returning an Array OUT (Uppercase Converter)
function capitalizeWords(arr: string[]): string[] {
  let result: string[] = [];
  for (let i = 0; i < arr.length; i++) {
    result[i] = arr[i].toUpperCase();
  }
  return result;
}

let words: string[] = ["hello", "world", "typescript"];
console.log(capitalizeWords(words));
// ["HELLO", "WORLD", "TYPESCRIPT"]

This is how a function "returns multiple values" — a function can only return ONE thing, but that one thing can be an array holding many values.

📌 Tuples — Fixed Length, Fixed Types

📖 Definition

A tuple is a fixed-length array where each position has a specific, pre-defined type. Used to group related fields of different types together.

AspectArrayTuple
LengthDynamic — grow anytimeFixed — set by declaration
Data type per positionSame type usually (or union)Fixed per exact position
Order of valuesFlexibleMust match declared type order
Basic Tuple Example
let person: [string, number] = ["John", 25];
// position 0 MUST be string, position 1 MUST be number
console.log(person[0]); // John
console.log(person[1]); // 25

person[0] = 30; // ❌ Error: number not assignable to string
🚨 Don't Confuse with Union Type!
let person: [string, number]; // TUPLE — 2 fixed slots
let x: string | number; // UNION — 1 slot, either type

Comma , inside brackets = tuple (multiple fixed positions). Pipe | = union (one value, multiple possible types). Visually similar syntax, completely different meaning!

Tuple with Multiple Values
let user: [number, string, boolean, number, string] =
  [10, "John", true, 101, "Kate"];
// order & types must match declaration exactly

All 3 loop styles (traditional for, for-in, for-of) work on tuples exactly the same as on arrays.

7

🗂️ Array of Tuples

📖 Combining Both

Wrapping a tuple type in [ ] creates an array that can hold multiple tuples.

// single tuple — only ONE record
let student: [number, string] = [101, "John"];

// array of tuples — MULTIPLE records
let students: [number, string][] = [
  [101, "John"],
  [102, "Peter"],
  [103, "Scott"]
];

console.log(students.length); // 3
console.log(students[0]); // [101, "John"]
console.log(students[0][0]); // 101
console.log(students[0][1]); // "John"
🚨 students[0][0] is NOT a 2D Array!

This is tuple-inside-array indexing: first bracket picks which tuple (record), second bracket picks which field inside that tuple. A true 2D array (rows/columns, like a[0,0]) is a different, rarely-used concept in TS/JS — not what's happening here.

8

⚡ Exam-Trick & Frequently Tested Points

Trick 1 — "Difference between array and tuple?"

Array = dynamic size, usually uniform type. Tuple = fixed size, fixed type PER POSITION.

Trick 2 — "Difference between for-in and for-of?"

for-in gives the index (need arr[i] to get value). for-of gives the value directly (no indexing needed).

Trick 3 — "Can a function return multiple values in TS?"

Yes — by returning an array (or tuple) that bundles multiple values into one returned object.

Trick 4 — "What does .length return for an array of length 5?"

5 — but the last valid index is 4 (length - 1). This distinction is the classic off-by-one trap.

Final One-Page Memory Sheet

📦 Array Basics

Stores multiple values (same or mixed types). Dynamic size. Index starts at 0.

🔢 Declaring Arrays

type[] or Array<type> — both work. Union (type1|type2) for mixed, any for anything.

🔁 3 Loop Types

Traditional for = manual control. for-in = auto index. for-of = direct value, no index.

🧩 Arrays + Functions

Pass array as parameter for input; return array to send back multiple values.

📌 Tuples

Fixed length, fixed type per position: [string, number]. Order & type must match exactly.

🗂️ Array of Tuples

[type,type][] holds multiple records. arr[0][1] = field 1 of record 0 — not a 2D array.
