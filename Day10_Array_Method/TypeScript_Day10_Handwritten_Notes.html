1

Quick Recap — .length is an Attribute, Not a Method

📖 Attribute vs Method

.length has no parentheses — it's a property. A method always ends with (), e.g. .push().

let numbers: number[] = [1, 2, 3, 4, 5];
let fruits: string[] = ["apple", "banana", "orange", "mango"];

console.log(numbers.length); // 5 — attribute, no ()
console.log(fruits.length); // 4

10 array methods today — these take primitive values as parameters. (Next class: 5-6 methods that take a function as a parameter — forEach, map, filter, reduce.)

2

➕➖ push() & pop() — Work at the END

push() adds at end

let numbers = [1, 2, 3, 4, 5];
numbers.push(6, 7); // add single or multiple values
console.log(numbers); // [1,2,3,4,5,6,7]

No need to know the last index — push figures it out and appends automatically.

pop() removes from end

let fruits = ["apple", "banana", "orange", "mango"];
let lastFruit = fruits.pop();
console.log(fruits); // ["apple","banana","orange"]
console.log(lastFruit); // "mango" — the removed element!

Removes only ONE element (the last one) and returns it — no parameters needed.

3

🔼🔽 shift() & unshift() — Work at the BEGINNING

shift() removes from start

let numbers = [1,2,3,4,5,6,7];
let firstNum = numbers.shift();
console.log(numbers); // [2,3,4,5,6,7]
console.log(firstNum); // 1 — the removed element

unshift() adds at start

let fruits = ["apple", "banana", "orange"];
fruits.unshift("kiwi", "pear");
console.log(fruits); // ["kiwi","pear","apple","banana","orange"]

Returns nothing (void) — just modifies the array in place.

Memorize this grid cold — it's asked constantly.

4

🔗 concat() — Combine Arrays

let numbers = [1,2,3,4,5,6,7];
let combined = numbers.concat([8, 9], [10]);
console.log(combined); // [1..10] — new array
console.log(numbers); // [1..7] — UNCHANGED!
🚨 Doesn't Mutate the Original!

Unlike push/pop/shift/unshift, concat() does NOT modify the original array — it returns a brand-new combined array. You must store the result in a variable to use it.

❌ Can't Mix Types
numbers.concat(fruits); // ❌ Error — number[] can't concat with string[]

Concat only works between arrays of the same type.

5

✂️ slice() — Extract a Section (Read-Only)

📖 Syntax
array.slice(startIndex, endIndex)

startIndex is inclusive. endIndex is exclusive — the element AT endIndex is NOT included.

4
fruits.slice(1, 3); // ["pear", "apple"] — index 3 excluded!
fruits.slice(2, 5); // ["apple", "banana", "orange"]
🚨 The "Exclusive End Index" Trap

slice(1, 3) → think of it as "up to 3 - 1 = 2". This off-by-one confusion is the #1 slice mistake. slice() never modifies the original array — it just returns a new sliced copy.

6

🔧 splice() — Add AND/OR Remove Anywhere

📖 Syntax
array.splice(startIndex, deleteCount, item1, item2, ...)

No end index here — instead, second param is a delete count. Optional items after that get INSERTED at startIndex.

Case 1 — Remove Only
let fruits = ["kiwi","pear","apple","banana","orange"];
let removed = fruits.splice(1, 2);
console.log(fruits); // ["kiwi","banana","orange"]
console.log(removed); // ["pear","apple"]

From index 1, delete 2 elements. Returns the removed elements.

Case 2 — Insert Only (deleteCount = 0)
let fruits = ["kiwi","banana","orange"];
fruits.splice(1, 0, "pineapple", "grape");
console.log(fruits);
// ["kiwi","pineapple","grape","banana","orange"]

0 deletions — existing elements just shift right to make room.

Case 3 — Remove AND Insert Together
let fruits = ["kiwi","pineapple","grape","banana","orange"];
fruits.splice(1, 2, "mango", "cherry");
console.log(fruits);
// ["kiwi","mango","cherry","banana","orange"]

pineapple & grape removed, mango & cherry inserted in their place — all in one call.

7

🔍 indexOf() & includes() — Searching

indexOf() — Returns Position
let fruits = ["kiwi","mango","cherry","banana","orange"];
fruits.indexOf("banana"); // 3
fruits.indexOf("papaya"); // -1 (not found)
fruits.indexOf("banana", 2); // search starts from index 2

2nd optional param = starting index to search from (skips earlier elements).

includes() — Returns Boolean
fruits.includes("apple"); // false
fruits.includes("banana"); // true
⭐ indexOf vs includes

indexOf → returns the position (or -1 if missing). includes → returns true/false directly. Use includes when you just need a yes/no check; use indexOf when you need the actual position.

8

🔤 toString() — Array to String

let numbers = [2,3,4,5,6,7];
let numbersString = numbers.toString();
console.log(numbers); // [2,3,4,5,6,7] (array)
console.log(numbersString); // "2,3,4,5,6,7" (single string!)

Converts the entire array into one comma-separated string — useful when you need to display or log array contents as plain text.

10

⚡ Exam-Trick & Frequently Tested Points

Trick 1 — "Difference between slice and splice?"

slice = read-only extraction, doesn't touch original. splice = actively adds/removes, modifies original in place.

Trick 2 — "Difference between shift/unshift and push/pop?"

shift/unshift work at the beginning. push/pop work at the end.

Trick 3 — "What does indexOf return if element not found?"

-1 — never null, never undefined. Always check against -1, not falsy checks.

Trick 4 — "Is slice's end index inclusive or exclusive?"

Exclusive — the element at that exact index is NOT included in the result.

★

Final One-Page Memory Sheet

➕➖ push / pop

push adds to end (single/multiple). pop removes only the last element, returns it.

🔼🔽 shift / unshift

shift removes first element, returns it. unshift adds to beginning, no return value.

🔗 concat

Combines arrays into a NEW array. Original untouched. Same type only.

✂️ slice vs 🔧 splice

slice(start,end) = read-only, end exclusive. splice(start,delCount,items) = mutates, adds/removes.

🔍 indexOf / includes

indexOf returns position or -1. includes returns true/false. Both accept optional start index.

🔤 toString

Converts array to one comma-separated string value.
