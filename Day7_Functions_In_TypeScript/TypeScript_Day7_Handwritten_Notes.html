What is a Function?

📖 Definition

A function is a reusable block of code that performs a task — but it only runs when you call/invoke it. The function itself does nothing on its own.

3 Types of Functions in TS
↙
Named
function keyword + name
↓
Anonymous
no name, stored in a variable
↘
Arrow / Lambda
=> syntax, most preferred
Function vs Method 🧠
Same definition! A function inside a class = "method". Functions exist without class/object.
2

🏷️ Named Functions — Syntax

function functionName(param1: type, param2: type): returnType {
  // body
}

functionName(arg1, arg2); // calling / invoking
No Params, No Return
function display(): void {
  console.log("Welcome to TypeScript");
}
display(); // must call it!
Params + Return Value
function addNumbers(x: number, y: number): number {
  return x + y;
}
console.log(addNumbers(2, 3)); // 5
Parameter vs Argument

Parameter = name used while defining the function. Argument = actual value passed while calling it. Often used interchangeably, but this IS the technical distinction.

3

⭐ 3 Special Parameter Types (Interview Favorites!)

📦 Rest Parameters

Accept unlimited values using .... Collected as an array.

❓ Optional Parameters

Mark with ? — caller may skip passing it.

🎁 Default Parameters

Assign a fallback value — used only when nothing is passed.

4

📦 Rest Parameters — Deep Dive

❌ Fixed Parameters — Strict Count
function addNumbers(x: number, y: number): number { return x + y; }
addNumbers(2, 3, 4); // ❌ Error: expected 2 arguments, got 3
addNumbers(2); // ❌ Error: expected 2 arguments, got 1
✅ Rest Parameters — Unlimited Values
function addNumbers(...nums: number[]): void {
  let sum = 0;
  for (let n of nums) { sum += n; }
  console.log(sum);
}
addNumbers(1, 2); // 3
addNumbers(1, 2, 3); // 6
addNumbers(10,20,30,40,50); // 150

Syntax: ...variableName: type[] — the ... (3 dots) collects all passed values into an array.

Rest Parameters with Multiple Types (Union)
function findElements(...elements: (number | string)[]): number {
  return elements.length;
}
findElements(3, "John", 1, 2, "Kate"); // 5
findElements(10, 20, 30, 40, 50, 60, 70); // 7

Combine rest params with union types to accept mixed data. .length is an array property returning count of elements.

5

❓ Optional Parameters — Deep Dive

function displayDetails(id: number, name: string, mail?: string): void {
  console.log(id);
  console.log(name);
  if (mail !== undefined) {
    console.log(mail);
  }
}

displayDetails(1, "Scott", "scott@gmail.com"); // prints all 3
displayDetails(2, "Kate"); // prints only id & name
🚨 Without the `if` Check

If you print an optional param that wasn't passed without checking, you'll get literal undefined printed — not skipped automatically! Always guard with if (param !== undefined).

⭐ CRITICAL RULE — Optional Parameter Ordering
// ❌ Error: required parameter cannot follow optional
function fn(id?: number, name: string) { }

// ✅ Correct — once optional starts, ALL following must be optional too
function fn(id?: number, name?: string) { }

Rule: Once you mark a parameter optional, every parameter after it must also be optional. Required params must always come first.

6

🎁 Default Parameters — Deep Dive

function calculateDiscount(price: number, rate: number = 0.50): void {
  let discount = price * rate;
  console.log("Discount amount:", discount);
}

calculateDiscount(1000, 0.30); // 300 (explicit value wins)
calculateDiscount(1000); // 500 (default 0.50 used)
Golden Rule

If you explicitly pass a value, it overrides the default. The default only kicks in when the argument is completely omitted from the call.

AspectOptional (?)Default (= value)
If not passedBecomes undefinedFalls back to the assigned value
Ordering ruleMust come after required paramsNo strict ordering rule like optional

👻 Anonymous Functions

📖 Definition

A function without a name — instead, it's assigned to a variable, and that variable acts as the function's name for calling it.

No Params Example
let msg = function(): string {
  return "Hello TypeScript";
};
console.log(msg()); // call via variable name
With Params Example
let multiply = function(a: number, b: number): number {
  return a * b;
};
console.log(multiply(10, 20)); // 200
Rest, optional & default parameters all work in anonymous functions too — no difference from named functions except: no name + must store in a variable.
8

🏹 Arrow Functions (Lambda) — Most Preferred!

📖 Definition

Arrow functions ARE anonymous functions — same rules apply, but instead of the function keyword, we use the fat arrow => (also called "goes-to operator"). Most used in real TS/automation code.

let variableName = (parameters): returnType => {
  // body
};
No Params, No Return
let greet = (): void => {
  console.log("Hello TypeScript");
};
greet();
Params + Return
let add = (a: number, b: number): number => {
  return a + b;
};
console.log(add(10, 20)); // 30
⭐ Implicit Return — Arrow Function Superpower

If the body has ONLY ONE return statement, you can drop the curly braces AND the return keyword entirely!

// Full version
let add = (a: number, b: number): number => { return a + b; };

// Implicit return — shorter!
let add = (a: number, b: number): number => a + b;
let multiply = (a: number, b: number): number => a * b;

Only works with a single-expression body — multiple statements still need { } and explicit return.

Rest / Optional / Default Params — All Work the Same in Arrow Functions
// Optional param example
let displayDetails = (id: number, name: string, mail?: string): void => {
  console.log(id, name, mail);
};

// Default param example
let calcDiscount = (price: number, rate: number = 0.50): void => {
  console.log(price * rate);
};

// Rest param example
let findElements = (...elements: (number|string)[]): number => elements.length;

Convert any named function to arrow: remove function keyword + name, add =>, store in a variable.

10

⚡ Exam-Trick & Frequently Tested Points

Trick 1 — "Are arrow functions a separate type?"

No! Arrow functions are technically a subtype of anonymous functions — just with shorter syntax using => instead of the function keyword.

Trick 2 — "Explain rest, optional, and default parameters with examples"

Classic interview ask — know all 3 definitions cold: Rest = unlimited args via .... Optional = ?, may be skipped. Default = fallback value via =.

Trick 3 — "Can a required parameter follow an optional one?"

No — TypeScript throws a compile error. Once optional starts, everything after must be optional too.

Trick 4 — "When does implicit return work?"

Only when the arrow function body is a single return expression — no curly braces, no return keyword needed.

11

🔁 Quick Revision Summary

Function = reusable code block, only runs when called
Named: function keyword + name. Called by name directly.
Anonymous: no name, stored in a variable
Arrow: anonymous + => syntax, most preferred
Rest (...x): unlimited args as array
Optional (x?): may skip, becomes undefined
Default (x=val): fallback when omitted
Implicit return: single-statement arrow fn, no braces/return
★

Final One-Page Memory Sheet

🏷️ Named Functions

function name(params): returnType { }. Called directly by name.

👻 Anonymous Functions

No name; must be stored in a variable. Variable name = how you call it.

🏹 Arrow Functions

(params): type => { }. Implicit return drops braces/return for single expressions.

📦 Rest Parameters

...name: type[] — unlimited arguments collected as an array. Combine with union type for mixed types.

❓ Optional Parameters

param?: type — skippable, becomes undefined. Must come after all required params.

🎁 Default Parameters

param: type = value — fallback used only when argument is fully omitted.
